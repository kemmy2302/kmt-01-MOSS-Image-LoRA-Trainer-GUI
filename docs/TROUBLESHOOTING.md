# トラブルシューティング

## PythonまたはGitが見つからない

64-bit版Python 3.10とGit for Windowsをインストールし、Windowsへ再ログインします。次の2つが成功することを確認してください。

```bat
py -3.10 --version
git --version
```

## セットアップ途中で止まる

- インターネット接続と空き容量を確認します。
- セキュリティソフトがPythonやGitを遮断していないか確認します。
- 原因を修正して`setup_windows.cmd`を再実行します。

## GUIが開かない

`start_gui.cmd`の画面に表示されたエラーを確認します。ポート8004が使用中なら、`config.json`の`port`を変更します。

## モデルが見つからない

`config.json`の`base_model`、`text_encoder`、`vae`が実在するファイルを指しているか確認します。パスは`D:/AI/models/file.safetensors`の形式を推奨します。

MOSS本体にはSFT版ではなくBase版、Text EncoderにはW4A8 GPTQ版ではなくConvRot INT8版が必要です。

## CUDA／Triton関連のエラー

- NVIDIAドライバーを更新します。
- `.venv`を別PCからコピーせず、そのPCでセットアップします。
- 本ツールは`triton-windows`を使います。Linux版`triton`へ置き換えないでください。

## VRAM不足・クラッシュ

- 解像度を1024から768または512へ下げます。
- ほかのGPU使用アプリを終了します。
- Windowsのページファイルを十分に確保します。
- `blocks_to_swap`は既定値24から始めます。

現在の検証基準はRTX 4070 12GBです。設定変更ですべてのGPUに対応できるわけではありません。

## タグ生成が初回だけ遅い

WD14モデルをHugging Faceからキャッシュへ取得するためです。2回目以降はローカルキャッシュを使います。

## 学習開始ボタンが有効にならない

画面上部の未作成数を確認します。すべての画像に空ではない同名`.txt`が必要です。一覧を再読み込みすると状態が更新されます。

## LANの別PCから接続できない

1. `listen_host`を`0.0.0.0`へ変更します。
2. Windowsファイアウォールでポートを許可します。
3. 学習PCの現在のIPv4アドレスを確認します。
4. `http://IPv4アドレス:ポート`を開きます。

認証機能はありません。ルーターのポート開放やインターネット公開は行わないでください。

## Issueへログを載せる前に

`runtime/training.log`にはユーザー名、ローカルパス、画像名が含まれる場合があります。必要な末尾だけを抜き出し、個人情報を削除してください。モデルや学習画像は添付しないでください。
