# Changelog

## 0.1.1 - 2026-11-07

- Detect 64-bit Python 3.10 from either the Python Launcher or `python` on PATH.
- Install `sd-scripts` requirements from the correct working directory.
- Use the repository-local `output` folder as the safe default output directory.
- Improve Windows console encoding and troubleshooting guidance.

## 0.1.0 - 2026-10-21

- Initial public release for Windows and NVIDIA GPUs.
- Added browser-based dataset and caption editor.
- Added WD14 caption generation and bulk tag operations.
- Added 9／12／15-image pagination.
- Added simplified training-strength presets and step estimates.
- Added training progress, log display, start, and stop controls.
- Added Windows setup scripts, configuration template, security guidance, and troubleshooting documentation.
